# Digital Literacy Project

This project contains various tasks and materials related to digital literacy skills.

## Project Structure

- `report/` - Project reports and documentation
- `task-1-presentation/` - Presentation materials and slides
- `task-2-portfolio/` - Digital portfolio components
- `task-3-platforms/` - Digital platform exploration and analysis
- `task-4-email-etiquette/` - Email communication best practices
- `task-5-cybercrime/` - Cybercrime awareness and prevention materials

## Getting Started

Each folder contains materials for specific digital literacy tasks. Navigate to the respective folders to access task-specific content.
